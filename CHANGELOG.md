# Изменения

## 5.1.0 — подготовка первого публичного установщика

- Самостоятельная Windows x64 сборка с Python/Tkinter/Pillow.
- Данные перенесены в отдельную папку пользователя; ресурсы только читаются из пакета.
- Нормальный перезапуск/открытие настроек через сигналы экземпляра, режим ожидания GPT.
- Чтение локальных журналов и автозапуск — отдельный выбор, по умолчанию выключены.
- Лицензия proprietary freeware, документация приватности и безопасности, CI и инструкции сборки.
- Установщик текущего пользователя и удаление только файлов своего манифеста с сохранением истории.

## 5.0 — локальная версия

- Три интерфейса, две темы, визуальная панель управления и атрибуция VLADMACC.
- Предпросмотр, применение/отмена, скрытие истории, адаптация Plus/Pro.
