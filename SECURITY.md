# Безопасность

Поддерживается текущая подготовленная ветка 5.1.x. Неподписанная сборка не считается подтверждённой
сертификатом издателя; проверяйте официальный репозиторий и контрольные суммы.

Для сообщения об уязвимости используйте **Report a vulnerability** в GitHub Security этого репозитория,
если приватный канал включён. Если его нет, создайте Issue с просьбой о приватном контакте, без деталей
эксплуатации, токенов, учётных данных или личных журналов. Не публикуйте секреты в открытых Issues.

Границы: приложение запускается от текущего пользователя, не требует администратора, не сохраняет
авторизацию и не вызывает генерацию моделей. Клиент разрешает только инициализацию и чтение
аккаунта/лимитов/статистики. Модельные, платёжные и почтовые методы запрещены.

Данные находятся вне каталога программы. Удаление использует явный список файлов сборки и маркер
установки; пользовательская история не удаляется. Обновления не скачиваются и не исполняются автоматически.

Не отключайте Defender/SmartScreen для установки. Если проверка не пройдена, сообщите о файле и его
SHA-256, не запускайте его в обход защиты.
