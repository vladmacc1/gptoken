# Работа с репозиторием

Исходники доступны для просмотра. Открытая лицензия на их изменение/распространение не предоставляется.
Перед внешним использованием, производной сборкой или передачей изменений согласуйте разрешение с VLADMACC.

Для ошибки укажите версию, Windows и архитектуру, точные шаги, ожидаемое и фактическое поведение.
Не загружайте `auth.json`, ключи, токены, пользовательские JSON, тексты чатов и персональную историю.

Для внутренних разрешённых изменений: отдельная ветка, тесты и форматирование, обновление версии,
CHANGELOG и документации при изменении поведения. Не включайте сборочные среды и бинарники в Git;
установщики публикуются как отдельные артефакты/релизы после проверки.
