# GPTOKEN: установка и использование

## Подготовка

Нужна Windows 10/11 x64 и официальный Codex с выполненным входом в аккаунт
ChatGPT. Проценты относятся к лимитам **Codex** на вашем тарифе. Приложение
не измеряет все сообщения обычного чата ChatGPT и не показывает остаток API-денег.
Токены — единицы обработки текста, а проценты лимита задаёт сервис; переводить
один процент в фиксированное число токенов нельзя.

## Установка

1. Скачайте установщик и `SHA256SUMS.txt` из одного официального релиза
   [vladmacc1/gptoken](https://github.com/vladmacc1/gptoken/releases).
2. Проверьте SHA-256 файла через `Get-FileHash` в PowerShell и сравните со списком.
3. Запустите установщик. Достаточно обычной учётной записи, Python не нужен.
4. Выберите папку, при желании — ярлык и запуск вместе с ChatGPT.
5. Откройте GPTOKEN из меню «Пуск». При первом запуске откроется страница данных.

Сборка без цифровой подписи имеет неподтверждённого издателя. Не отключайте
защиту Windows; при сомнениях дождитесь подписанного релиза. Наличие контрольной
суммы проверяет совпадение файла, но само по себе не подтверждает безопасность.

## Главное окно и настройки

- Процент и заполнение полосы — оставшаяся квота соответствующего окна.
- Таймер — время до сброса. Разные окна расходуются независимо.
- Для Plus показываются пятичасовое и недельное окна. Для семейства Pro
  интерфейс показывает недельное. Если сервис не прислал нужное окно, будет «—».
- Обновление запрашивает свежие данные; состояние кнопки показывает ожидание,
  успех или ошибку. Обычно опрос идёт раз в 45 секунд, при локальной активности —
  раз в 12 секунд. Необязательная суммарная статистика обновляется реже.
- Три точки открывают боковое меню по нажатию. Повторное нажатие, крестик или
  Escape закрывают его. Панель управления открывает полноценные настройки.
- Перетащите окно за свободную область. Кнопки отдельно обрабатывают нажатия.

В «Оформлении» есть три стиля, тёмная и светлая тема, четыре размера. Мини
шириной 60 px показывает батарейку и процент. Справа — предпросмотр. Примеры
Plus/Pro меняют только предпросмотр; реальный тариф определяется автоматически.
Нажмите «Применить», чтобы сохранить выбор. «Отмена» не применяет черновик.

В «Поведении» доступны прозрачность, положение поверх окон, анимация,
уведомления и расчёт бюджета по будням. Чтение технических маркеров журналов
Codex включается отдельно и по умолчанию выключено. Оно ускоряет реакцию
анимации, но не делает проценты сервиса непрерывными и не измеряет токены/секунду.

## Индикатор состояния ChatGPT

В левом верхнем углу есть отдельная точка, в том числе в размере 60 px.
Нажмите её: сбоку откроются пояснение, время последней проверки и ссылка на
[официальную страницу состояния](https://status.openai.com/). Повторное нажатие,
крестик или Escape закрывают панель; наведение её не открывает.

- Зелёная — в проверенных компонентах ChatGPT не заявлено проблем.
- Жёлтая — ухудшение, частичная недоступность или обслуживание.
- Красная — крупный сбой одного из проверенных компонентов ChatGPT.
- Серая — проверка ещё не прошла, произошла ошибка, изменился формат источника
  или нет свежих данных. Отсутствие ответа не считается исправной работой.

Виджет читает публичный JSON `https://status.openai.com/api/v2/summary.json`
при запуске, затем **раз в 5 минут**. При ошибках — через 10 минут, затем каждые
15 минут до успешного ответа. Проверка идёт в отдельном потоке и не задерживает
окно или обновление лимитов. Перезапуск запускает новую проверку; кнопка
обновления лимитов не учащает проверки сайта статуса.

**Расход — 0 модельных токенов.** Для этой функции не нужны API-ключ, платная
подписка или запрос к GPT. Это обычное чтение сайта: используются сеть и ресурсы
ПК, источник видит стандартные данные HTTP-соединения. Лимиты, чаты и учётные
данные виджета ему не передаются.

Проверяются компоненты ChatGPT, а не общий цвет всех продуктов OpenAI: сбой
только API или Codex не перекрашивает этот индикатор. Это опубликованная сводка,
не проверка вашего аккаунта или соединения с ChatGPT. Сам источник может
сообщать о проблеме с задержкой; затем виджет увидит её при следующем опросе.

## Почему анимация может запаздывать

Частота кадров, события активности и проценты квоты — разные данные. Анимация
рисуется локально. При включённом быстром отклике технические маркеры журналов
проверяются раз в секунду, новые файлы обнаруживаются раз в две секунды.
Реакция следует за записью маркера; сервер может записать его позже реальной работы.
Без журналов анимация реагирует на измеренное изменение квоты, которое приходит
при опросе: обычно 45 секунд, во время обнаруженной активности — 12 секунд.

Более частое чтение служебных данных **само по себе не тратит модельные токены**,
но увеличивает нагрузку и не делает серверные данные точнее. В текущем интерфейсе
Codex нет гарантированного потока точного расхода всего аккаунта каждую секунду.
Пробные вопросы модели расходовали бы токены, но виджет их не отправляет: такие
вопросы не измеряют расход других чатов и не нужны для анимации или статуса.

## Для чего графики и расчёты

Полоса отвечает «сколько осталось сейчас», график — «как менялся остаток».
Провал означает расход, рост после сброса — начало нового окна. Пропуски
и сбросы разрывают линию; это не непрерывное наблюдение за выключенным ПК.
Историю можно скрыть. Для двух лимитов рисуются независимые графики.

Темп вычисляется по изменениям процентов на временном отрезке и выражается
в процентных пунктах в час. Дневной бюджет делит остаток на доступные дни.
Прогноз предполагает сохранение наблюдаемого темпа, поэтому не гарантирует
дату исчерпания. Сеанс считает изменения после начала локального сеанса,
а не выставляет счёт. Суммарные токены показываются только при наличии
соответствующего ответа Codex.

## Если данных нет

Откройте Codex и проверьте вход, затем перезапустите виджет. Для нестандартной
установки можно задать переменную `VLADMACC_CODEX_PATH` полным путём к
настоящему `codex.exe`. Командные строки, `.cmd` и `.bat` не принимаются.
При отсутствии сети или изменении протокола данные могут быть устаревшими;
виджет не подставляет выдуманный остаток.

## Автозапуск, завершение и удаление

Опция установщика добавляет наблюдатель при входе в Windows. Он ждёт запуск
настольного ChatGPT и открывает виджет один раз. Если вручную закрыть виджет,
он появится при следующем запуске ChatGPT. Наблюдатель не читает тексты окон.
Новая установка с автозапуском начнёт наблюдать после следующего входа в Windows.

Закройте через меню виджета. Для остановки также наблюдателя используйте
`CodexUsageWidget.exe --quit`. Удалите GPTOKEN через «Установленные приложения».
История остаётся в `%LOCALAPPDATA%\VLADMACC\CodexUsageWidget`. Удалять её
вручную стоит только после проверки, что данные больше не нужны.

Штатная работа виджета не запускает модель, не покупает токены и не расходует
модельные токены. Запросы метаданных и ресурсов компьютера всё равно выполняются.
Подробности — [PRIVACY.md](../PRIVACY.md).
