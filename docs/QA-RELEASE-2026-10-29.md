# GPTOKEN 5.1.0 — текущий кандидат выпуска

Этот отчёт относится к `candidate-05`. Предыдущие кандидаты сохранены для истории
проверок; их установщики в итоговый комплект не входят. Публичный бинарный релиз
в GitHub Releases пока не опубликован.

## Состав и статус проверки

Среда сборки обновлена до CPython 3.14.10, OpenSSL 3.5.9 и Tcl/Tk 9.0.4.
Причина: официальный OpenSSL сообщает об исправлениях в 3.5.9, отсутствующих
в 3.5.8 из предыдущего локального кандидата. Источник:
[OpenSSL security advisories](https://openssl-library.org/news/vulnerabilities/index.html).
Лицензии соответствующих компонентов включены в установщик, в том числе полный
LICENSE Windows-дистрибутива Python. Среда извлечена из официального архива;
системная установка Python, PATH и реестр при подготовке среды не менялись.

Код индикатора и анимации тот же, что прошёл независимую проверку и тесты.
Код состояния, HTTPS-запросы и локальная анимация не запускают модель.
Настройки частоты и границы точности описаны в [инструкции](USER_GUIDE.ru.md).

на других устройствах. Проверки GUI выполнялись с синтетическими квотами;
отдельное живое подключение использовало текущий аккаунт с чтением метаданных.

Код приложения соответствует `e080f79`; после него изменены тест совместимости
парсера, документация и уведомления о компонентах. Бинарный пакет содержит снимок
инструкции и отчётов до выполнения итоговых проверок. Эта обновлённая версия
отчёта включена отдельно в комплект и в репозиторий.

Windows CI на Python 3.14.10 успешно собрал и проверил приложение в
[run 40926148832](https://github.com/vladmacc1/gptoken/actions/runs/40926148832)
и [run 40926636084](https://github.com/vladmacc1/gptoken/actions/runs/40926636084).
Итог CI для точного последнего коммита комплекта записан в `CI-RESULT.json`;
архив комплекта формируется только после его успешного завершения. Сам CI
сохраняет отдельные артефакты и не публикует релиз.

## Границы готовности

- Нужен установленный официальный Codex и выполненный вход в аккаунт.
- Проверки на чистых Windows 10/11, обычной установке с ярлыками/автозапуском
  и реальном Plus ещё не завершены. Живое подключение ранее проверено на Pro.
- Цифровой подписи пока нет; сертификат не приобретался.
- Штатное удаление отдельно согласовано и проверено на `candidate-03` с сохранением
  посторонних файлов и истории. Код удаления не менялся; новые тестовые установки сохраняются.
- Полный Security-аудит относится к прежнему снимку. Новый клиент статуса дополнительно
  прочитан независимо, найденные дефекты исправлены; это не новый полный аудит зависимости.
