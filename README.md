# GPTOKEN · Codex Usage Widget

Бесплатный локальный виджет лимитов Codex для Windows от **VLADMACC**.
Три интерфейса, светлая/тёмная тема, визуальный выбор оформления и отдельные окна Plus/Pro.

Статус: подготовка первой публичной сборки. До утверждения релиза файл установки
может отсутствовать в Releases. Проверки и ограничения указаны в [чек-листе](docs/RELEASE_CHECKLIST.md).

**Публичный репозиторий не означает открытую лицензию. Все права на приложение,
исходники и оформление принадлежат VLADMACC.** Условия бесплатного запуска — в [LICENSE](LICENSE).

## Установка

1. Установите официальный Codex для Windows и войдите в свой аккаунт ChatGPT.
2. Скачайте `GPTOKEN-5.1.0-windows-x64-setup.exe` из [Releases](https://github.com/vladmacc1/gptoken/releases).
3. Запустите установщик. Python, Pillow и Tkinter отдельно не нужны — они входят в сборку.
4. При первом запуске откроется панель настройки/подключения. Затем выберите оформление и нажмите «Применить».

Целевая платформа: Windows 10/11, x64. Codex и аккаунт в пакет не входят.
Приложение не связано с OpenAI организационно и не является официальным продуктом OpenAI.

Файл установки пока может быть **без цифровой подписи**: издатель в проверке Windows не будет подтверждён
сертификатом. Не отключайте защиту Windows. Проверяйте источник загрузки и SHA-256 из `SHA256SUMS.txt`.
Подписание и публичная публикация отмечаются отдельно в отчёте релиза.

## Возможности

- Автоматически получает тип подписки и реальные окна лимита; не выдумывает отсутствующие проценты.
- Plus — пятичасовое и недельное окно; семейство Pro — недельное.
- Мягкий минимализм, приборная панель, компактный; две темы и четыре размера, включая батарейку 60 px.
- Три точки работают по нажатию. Панель управления содержит точный предпросмотр и примеры Plus/Pro.
- Полоса показывает остаток сейчас; график — его изменение. Историю можно скрыть без остановки расчётов.
- Локальные настройки и история. Штатная работа не вызывает генерацию GPT и расходует 0 модельных токенов.
- Индикатор состояния ChatGPT слева: официальный публичный статус, опрос раз в 5 минут, без модельных токенов.

Уведомления не отправляются в сторонние приложения. Покупки, письма, запуск модельных задач и изменение
подписки не входят в разрешённые методы клиента.

## Приватность и дополнительные функции

Чтение локальных журналов Codex для быстрой анимации **по умолчанию выключено**. Оно включается
отдельно в «Панель управления → Поведение», с объяснением, что читается.
Автозапуск вместе с GPT выбирается отдельно в установщике; по умолчанию выключен.

Данные хранятся в `%LOCALAPPDATA%\VLADMACC\CodexUsageWidget`, отдельно от файлов приложения.
Удаление программы сохраняет эту папку, чтобы не потерять историю. Подробности — [PRIVACY.md](PRIVACY.md).

## Разработка и проверки

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
$env:PYTHONPATH = "src"
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m ruff check src tests scripts
.\.venv\Scripts\python.exe -m ruff format --check src tests scripts
```

Для собранного EXE предусмотрены офлайн-проверка `--self-test` и изолированная GUI-проверка
`--smoke-test` с обязательным `--data-dir`. Они не отправляют запросы к модели и не требуют входа для
демонстрационных данных. CI собирает проверяемые артефакты; публикация релиза выполняется отдельно.

Сообщения об ошибках не должны содержать `auth.json`, токены, тексты чатов или персональные истории.
